# strangersh

A name derived from my dictionary by combining two words stranger and ssh. The project is designed to make you feel like you're chatting with a stranger and also use SSH. 

A chatbot type project that tries to act like a human and we (the actual human) will knowingly waste our time chatting with a bot.

I've used nemotron 3.5 30b model to have quick response and its also not super demanding like GLM. Thinking has also been turned off to have quicker output.


# Idea:

I got this random idea out of nowhere. Few weeks ago me and my friends used a website in computer lab where we would chat with strangers from different place.
